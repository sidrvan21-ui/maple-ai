## What each note must contain

1. **Plain English** — what this part is
2. **Why it exists** — the Maple rule it implements
3. **What we created** — paths and what each file does
4. **How we made it** — commands, order of work, decisions we picked
5. **Interview script** — questions and the answer you will say
6. **Gotchas** — what breaks if you skip a piece
7. **How to demo** — exact clicks or curl
8. **On to next** — one line
